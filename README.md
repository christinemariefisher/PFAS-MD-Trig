The code provided in PFAS-MD-Trig is described and used in the manuscript titled "Improved Non-Targeted Coverage of Per- and Polyfluoroalkyl Substances (PFAS) Using Mass Defect-Informed Data-Dependent Analysis" (https://doi.org/10.1021/acs.analchem.6c05542). Brief descriptions are provided below. For additional information please refer to the manuscript.
"Histograms_Input.csv" is an example input for the "Histograms_OptimalMDRagne.py" and "Histograms_Visualization.py" codes.
"Histograms_OptimalMDRange.py" is the code used to determine the optimal mass defect range the minimized coverage of non-PFAS/food features and maximized coverage of PFAS compounds.
"Histograms_Visualization.py" is the code used to generate four overlayed histograms to visualize/compare the overlap of 4 distributions.
"PFASstds.csv" is an example input file used with the "PFASstds_MS2matches_batch.py" code. MS2 triggering data was searched against this list of standards.
"PFASstds_MS2matches_batch.py" is the code used to determine which MS2 spectra corresponded to the spiked PFAS standards listed in the input "PFASstds.csv" file.
